Put the record on your page.

One line of code. The live tally and the last graded row from the record, on your newsletter, your blog, your show notes. The numbers come from the ledger at the moment your page loads. Nobody types them, nobody can flatter them, and when a call is wrong your readers see it before this desk does.

The tag

<script src="https://thesimplifier7.com/record-embed.js" async></script>

Paste it where you want the card. It sizes to its container up to 420 pixels wide.

Options

data-theme="dark"      dark card, default light
data-width="320px"     fixed width, default fills the container
data-rows="2"          latest graded rows shown, 0 to 3, default 1

What it does not do

  • No cookies, no tracking, no third party. It fetches one JSON file from the record and nothing else.
  • It never shows a stale number. If the record cannot be reached it renders one plain link and no figures.
  • It cannot be edited to say something the ledger does not. Every figure is read from record.json, which is generated from the same file that renders the page.
  • It does not sell anything. There is no seat, no price and no application on the card. The only link is the record.

Substack

Substack does not run scripts in posts. Use the card image instead: save the latest tally card and link it to the record. It is regenerated every Friday from the same JSON.
