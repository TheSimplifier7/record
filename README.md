# record

The public track record of THE SIMPLIFIER, gold and silver intelligence.

**Live record: https://thesimplifier7.github.io/record/**

Every call is named before the move and graded after. Wins and misses sit in the same place. Nothing is ever removed. The file only grows, and the full commit history of this repository is the proof. If a call was wrong, it is still here.

## How a call is graded

Every claim ships with the exact close that would prove it wrong, published with the call, before the move.

Friday at the weekly close, every open claim is graded in public. Right, wrong, or never reached.

A level that was never reached is stated as no test and counted for neither side. It is never banked as a win.

Grades are never restamped to fit a rulebook written after them. The standard tightened on 3 July 2026, and earlier entries are marked as pre-standard and left exactly as they were graded.

Corrections are published on the page as numbered notes, including the ones against this desk.

## Cadence

Map on Sunday. Method on Wednesday. Verdict on Friday. All 23:00 CET, and the Verdict at 23:30 because the weekly close prints at 23:00 and nothing is graded before the candle closes.

## The standing calls

Two directional calls run on their own clocks, graded separately, and never counted in the strike tally. Each carries the condition that would end it.

We name the line. We do not forecast. We grade in public.

Named before. Graded after. Nothing deleted.
